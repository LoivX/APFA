# Exercise 3 #
## Exercise Rubric ##
Write a program that reads an integer n, checks whether the entered number is prime or not and prints a corresponding message.

## Exercise comments ##
In this exercise i used the square root of the inserted number to fix a ceiling to the divisors that must to be checked to guarantee that the number is prime. 
Then the loop is performed and as soon as a divisor is found the loop is interrupted.
If no divisor is found the program prints that the number is prime.
