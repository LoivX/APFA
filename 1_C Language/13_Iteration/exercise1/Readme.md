## Exercise comments ##
There are 3 different files containing 3 different infinite loops:
-   *infinite_for.c* contains the infinite for loop that prints a funny line forever since no condition has been given
- *infinite_while.c* contains an infinite while loop that prints a line forever since the condition to the while is always different from 0 (it is 1)
- *infinite_do-while.c* contains an infinite do-while loop that prints a line forever as the case listed before.
