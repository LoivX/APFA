# Exercise 3 #
## Exercise Rubric ##
Write a program that reads a positive integer n from the keyboard and prints to the terminal a square of asterisks with side length n.

## Exercise comments ##
In this program I inserted a check on the positiveness of the number to ensure a positive number is inserted. Otherwise a loop forces the user to do so.
I used a nested for loop to fill the 'matrix' of asterisks counting the rows (external for loop) then the characters per row (internal for loop).
