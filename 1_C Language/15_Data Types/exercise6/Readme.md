# Exercise 6 #
## Exercise Rubric ##
Write a program that declares a dynamically allocated matrix, reads its dimensions and then the values of its elements from the terminal window, and finally calculates and prints the number of elements for which M[i][j] == i + j.

## Exercise comments ##
The program prints out only the position and the element at which the condition is satisfied. If no elemento satisfies the requirement than a boolean allows to  notify the user that no element has been found.
