# Introduction #
In this section you'll find all the results to the first exercises assigned. 



## *Algorithms* ##
This directory contains the solution to the exercises on algorithms, provided in form of *pseudocode* and *flowcharts*.

## *gitTesting* ##
This directory contains the results to the requested git commands provided in form of screenshots of the terminal in which they've been executed. Moreover there are the test files created to test git functionalities.

## *ssh Protocol* ##
This directory contains the screenshots of the results of the commands needed to establish an ssh connection, generate keys and automize the login with keys. 
It also contain the config file used to set up the connection shortcut.
